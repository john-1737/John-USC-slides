\begin{foundframe}[t]
    \frametitle{Some Useful Facts}

    \framesubtitle{Var and Cov}

    \begin{itemize}
        \item $\operatorname{Cov}(X,X) = \operatorname{Var}(X)$
        \item $\operatorname{Var}(X+Y) \neq \operatorname{Var}(X) + \operatorname{Var}(Y)$, in general
        \item $\operatorname{Cov}(X+Y,Z) = \operatorname{Cov}(X,Z) + \operatorname{Cov}(Y,Z)$
        \item  The variance of a portfolio is the weighted sum of all the covariance terms: 
        $$\sigma_p^2 = \sum_{i=1}^{n}\sum_{j=1}^{n}
                w_iw_j\operatorname{Cov}(r_i,r_j)$$
        \item Using the fact that $\operatorname{Cov}(X,X) = \operatorname{Var}(X)$, this can be written:
        $$\sigma_p^2 = \sum_{i=1}^{n}w_i^2\sigma_i^2 + 2\sum_{i=1}^{n}
    \sum_{\substack{j=1\\j\neq i}}^{n} w_iw_j\operatorname{Cov}(r_i,r_j)$$
        
    \end{itemize}

\end{foundframe}

\begin{foundframe}[t]
    \frametitle{Some Useful Facts}
    \framesubtitle{Calculus}

    \begin{itemize}
        \item Chain rule: 
        $$\frac{d}{dx}f(g(x)) = f'(g(x))*g'(x)$$
        \item Product rule: 
        $$\frac{d}{dx}f(x)g(x) = f'(x)g(x) + f(x)g'(x)$$
        \item Quotient rule: 
        \begin{align*}
            \frac{d}{dx}\frac{f(x)}{g(x)} &= \frac{d}{dx}f(x)g(x)^{-1}\\
            &= f'(x)g(x)^{-1} - f(x)g'(x)g(x)^{-2} \\
            &= \frac{f'(x)g(x) - f(x)g'(x)}{g(x)^2}
        \end{align*} 
    \end{itemize}

\end{foundframe}

\begin{frame}[t]
    \frametitle{1. The Market Portfolio and Equilibrium}
    \framesubtitle{Markowitz Portfolio Optimization}

    Notes:
    \begin{itemize}
        \item If all investors are mean-variance optimizers and have the same expectations about returns, variances, and covariances, they will choose the same optimal portfolio of risky assets.
        
        \begin{itemize}
            \item The optimal risky portfolio is the portfolio that maximizes
            the Sharpe Ratio.
        \end{itemize}
    
        \item Investors may have different allocations between the risky portfolio and the risk-free asset because they have different levels of risk aversion.
    
        \item If all investors hold the same risky portfolio, and all investors have access to the same assets, then in equilibrium that portfolio must be the \textbf{market portfolio}. \item Thus, the market portfolio must itself be mean-variance efficient.

    \end{itemize}

\end{frame}

\begin{frame}[t]
    \frametitle{1. The Market Portfolio and Equilibrium}
    \framesubtitle{Markowitz Portfolio Optimization}

        Continued...

        \begin{itemize}
        \item Mean-variance optimization tells investors which portfolios are
        optimal given expected returns, variances, and covariances, but does not
        by itself determine equilibrium expected returns.
    
        \item The observation that the market portfolio must be optimal has strong implications for the \textit{relationship between the expected returns of different assets}. This is the basis of the \textbf{Capital Asset Pricing Model (CAPM)}.
    \end{itemize}

\end{frame}

\begin{frame}[t]
    \frametitle{1. The Market Portfolio and Equilibrium}
    \framesubtitle{CAPM assumptions}

    \begin{itemize}
    \item Investors are similar
        \begin{itemize} 
            \item Investors are mean-variance optimizers
            \item Investors have the same expectations for asset characteristics (means, variances, correlations)
            \item Investors have the same time horizons
        \end{itemize}
    \item Markets are frictionless
        \begin{itemize} 
            \item All assets are publicly traded and available to all investors.
            \item No taxes
            \item No trading costs
            \item Unlimited leverage available at the risk-free rate
            (and therefore short positions allowed)
        \end{itemize}
    \end{itemize}

    These may seem overly restrictive.   Some can be relaxed and CAPM still holds.  
    More importantly, CAPM is, like all models, a useful simplification.

\end{frame}

\begin{frame}[t]
    \frametitle{1. The Market Portfolio and Equilibrium}
    \framesubtitle{CAPM Conclusion: Equilibrium}

        \begin{itemize}
            \item All investors hold the same optimal risky portfolio.
            
            \item Because investors collectively own all traded securities, this
            portfolio is the \textbf{market portfolio}.
            
            \item Therefore, the market portfolio must be mean-variance efficient.
            
            \item This places a restriction on the expected return of every
            individual security.
            
            \item If a security's expected return deviates from this restriction,
            investors will buy or sell the security. This changes its price and,
            therefore, its expected return.
            
            \item This process continues until an \textbf{equilibrium} is reached:
            expected returns satisfy the equilibrium relationship and investors
            are willing to hold the market portfolio.
        \end{itemize}

    \blfootnote{The \textbf{expected return of the entire market} is determined by economic factors (wealth, average risk aversion, risk-free rate).   We'll have more to say about that in later classes}

\end{frame}


\begin{frame}[t]
\frametitle{2. The Equilibrium Condition for Expected Returns}
    \section{The Equilibrium Condition for Expected Returns}
\framesubtitle{Approach 1: Derivative of the Sharpe Ratio w.r.t. $w_i$}

\begin{itemize}
    \item If the market portfolio is optimal, then the derivative of the Sharpe Ratio of the market portfolio with respect to a single security $i$ will be zero.  
    \item Start with the numerator of the Sharpe Ratio.  An increase in $w_i$ must be financed by an equal decrease in the allocation to the risk-free asset.   Therefore, the derivative of the numerator with respect to $w_i$ is 
    \[
    \frac{\partial (E[r_m]-r_f)}{\partial w_i}
    =
    E[r_i]-r_f.
    \]
    The $-r_f$ is the risk-free return lost when the allocation to
    asset $i$ is increased, or equivalently the cost of leverage if the investor borrows money to increase $w_i$


\end{itemize}

\end{frame}

\begin{frame}[t]
\frametitle{2. The Equilibrium Condition for Expected Returns}
\framesubtitle{Approach 1: Derivative of the Sharpe Ratio w.r.t. $w_i$}

\begin{itemize}
    \item The denominator is the standard deviation of the portfolio
    \[
    \sigma_m
    =
    \sqrt{
        \sum_j w_j^2\sigma_j^2
        +
        2\sum_{j<k}w_jw_k
        \operatorname{Cov}(r_j,r_k)
    }.
    \]
    \item Differentiating with respect to $w_i$ gives (use the Chain Rule)
    
    \[
    \frac{\partial \sigma_m}{\partial w_i}
    =
    \frac{
        w_i\sigma_i^2
        +
        \sum_{j\ne i}w_j\operatorname{Cov}(r_i,r_j)
    }{\sigma_m}.
    \]

    \item By the linearity of covariance we can rewrite the top as:
    \[
    \operatorname{Cov}(r_i,r_m)
    =
    w_i\sigma_i^2
    +
    \sum_{j\ne i}w_j\operatorname{Cov}(r_i,r_j).
    \]

    \item Therefore:
    \[
    \frac{\partial \sigma_m}{\partial w_i}
    =
    \frac{\operatorname{Cov}(r_i,r_m)}{\sigma_m}.
    \]
\end{itemize}

\end{frame}

\begin{frame}[t]
\frametitle{2. The Equilibrium Condition for Expected Returns}
\framesubtitle{Approach 1: Derivative of the Sharpe Ratio w.r.t. $w_i$}

\begin{itemize}
    \item Now we have the derivative of the numerator and the derivative of the denominator.   Next we use the quotient rule to get the derivative of the ratio:
    \[
    \frac{\partial}{\partial w_i}
    \left(
        \frac{E[r_m]-r_f}{\sigma_m}
    \right)
    =
    \frac{
        (E[r_i]-r_f)\sigma_m
        -
        (E[r_m]-r_f)
        \dfrac{\operatorname{Cov}(r_i,r_m)}{\sigma_m}
    }{\sigma_m^2}.
    \]

    \item Set this derivative equal to zero:
    \[
    (E[r_i]-r_f)\sigma_m
    -
    (E[r_m]-r_f)
    \frac{\operatorname{Cov}(r_i,r_m)}{\sigma_m}
    =0.
    \]

    \item Rearranging gives
    \[
    \frac{E[r_i]-r_f}
         {\operatorname{Cov}(r_i,r_m)}
    =
    \frac{E[r_m]-r_f}{\sigma_m^2}.
    \]
\end{itemize}

\end{frame}

\begin{frame}[t]
\frametitle{2. The Equilibrium Condition for Expected Returns}
\framesubtitle{Approach 1: Derivative of the Sharpe Ratio w.r.t. $w_i$}

\textbf{Summary}

\begin{itemize}
    \item If the market portfolio is the optimal risky portfolio, then
    a marginal increase in the weight of any security, financed by a
    decrease in the risk-free asset, cannot increase the market
    portfolio's Sharpe ratio. Therefore,
    \[
    \frac{\partial S_m}{\partial w_i}=0.
    \]

    \item This first-order condition implies
    \[
    \frac{E[r_i]-r_f}
         {\operatorname{Cov}(r_i,r_m)}
    =
    \frac{E[r_m]-r_f}
         {\sigma_m^2}.
    \]

    \item Equivalently,
    \[
    E[r_i]-r_f
    =
    \frac{\operatorname{Cov}(r_i,r_m)}
         {\operatorname{Var}(r_m)}
    \bigl(E[r_m]-r_f\bigr).
    \]
\end{itemize}
    

\end{frame}

\begin{frame}[t]
    \frametitle{2. The Equilibrium Condition for Expected Returns}
    \framesubtitle{Approach 2: The Market Price of Risk}

    \textbf{Approach 2: The Market Price of Risk}\\
    \textit{Note: this follows the presentation in the textbook}\\
    \vspace{1em}

    Define the reward-to-risk for investment in the market portfolio as follows:

    $$\frac{\text{Market Risk Premium}}{\text{Market Variance}} = \frac{E[r_m]-r_f}{\operatorname{Var}(r_m)}$$

    This is referred to as the "market price of risk".
  
    \vspace{1em}
    \blfootnote{Notice that this is \textit{not} the same as the Sharpe Ratio, which has the standard deviation in the denominator.  Using variance instead makes this comparable to the covariance, which will be relevant when we consider the contribution of one particular security to the market portfolio, as we do in the next slide.}
    \vspace{1em} 

\end{frame}

\begin{frame}[t]
    \frametitle{2. The Equilibrium Condition for Expected Returns}
    \framesubtitle{Approach 2: The Market Price of Risk}

    Single securities are evaluated by their contribution to the market portfolio because, under CAMP assumptions,  all investors already hold the market portfolio.\\
    \vspace{1em}

    The contribution of security $i$ to the reward from the market portfolio is the expected excess return:
    $$w_i(E[r_i] - r_f)$$
    The  contribution of a security $i$ to the risk of the market portfolio is given by:
    $$\sum_{j=1}^{n}w_i w_jCov(r_i,r_j) = w_{i}Cov(r_i,r_m)$$
    This uses the fact that the Covariances are additive.
\end{frame}

\begin{frame}[t]
    \frametitle{2. The Equilibrium Condition for Expected Returns}
    \framesubtitle{Approach 2: The Market Price of Risk}

    The reward-to-risk for a single security $i$ is therefore:
     $$\frac{w_i(E[r_i] - r_f)}{ w_{i}Cov(r_i,r_m)}$$
     The $w_i$ cancel out, leaving
    $$\frac{E[r_i] - r_f}{Cov(r_i,r_m)}$$

\end{frame}

\begin{frame}[t]
    \frametitle{2. Implications of CAPM Equilibrium}
    \framesubtitle{Approach 2: The Market Price of Risk}

    From Bodi et al, p 119:
    \vspace{1em}

    \begin{quote}
    A basic principal of equilibrium is that all investments should offer the same reward-to-risk ratio.
    If the ratio were better for one investment than another, investors would rearrange their portfolios.
    This would cause prices to adjust until the expected reward-to-risk were equal.
    \textbf{Therefore, we conclude that the reward-to-risk for each security is equal to the reward-to-risk for the market portfolio.}
    \end{quote}


\end{frame}

\begin{frame}[t]
    \frametitle{2. Implications of CAPM Equilibrium}
    \framesubtitle{Approach 2: The Market Price of Risk}


    Using our definitions and the previous slide implies the following equilibrium condition:

    $$\frac{E[r_{i}]-r_f}{\operatorname{Cov}(r_i,r_m)} = \frac{E[r_m]-r_f}{\operatorname{Var}(r_m)}$$
    
    Rearranging:
    $$E[r_i] - r_f = \frac{\operatorname{Cov}(r_i,r_m)}{\operatorname{Var}(r_m)}(E[r_m]-r_f)$$
    \vspace{1em} 

    In words, the reward-to-risk for every security is equal to the market price of risk.  Also note that this is the same equilibrium condition as we derived in Approach 1.

\end{frame}

\begin{frame}[t]
    \frametitle{3. Implications of CAPM Equilibrium}
    \section{Implications of CAPM Equilibrium}
    \framesubtitle{Defining $\beta$}

    Define the Beta of a security as as:
    $$\beta_i = \frac{\operatorname{Cov}(r_i,r_m)}{\operatorname{Var}(r_m)}$$
    A few different ways to think about $\beta_i$:
    \begin{enumerate}
        \item This comes straight out of the equilibrium conditions we have been deriving.
        \item $\beta_i$ is risk each dollar invested in security $i$ contributes to the risk of the market portfolio, as a share of the overall risk of the market portfolio.
        \item It's a regression coefficient.   Specifically, it's the regression coefficient for $E[r_i]-r_f$ on $E[r_m]-r_f$.   Regression coefficients measure the sensitivity of the 
        excess returns of security $i$ to variation in the market excess returns.
    \end{enumerate}

\end{frame}

\begin{frame}[t]
    \frametitle{3. Implications of CAPM Equilibrium}
    \framesubtitle{Prices Adjust}

    Draw the Security Market Line (SML) using the following considerations:
    \begin{itemize}
        \item If a security is uncorrelated with the market, then overweighting that 
        security will reduce the variance of the resulting portfolio.   
        The return on this security must be equal to the risk-free return, 
        otherwise it would be possible to construct a better portfolio than the market, 
        thereby violating the equilibrium condition.
        \item If a security is perfectly correlated with the market and had a better 
        expected return than the market portfolio, then that would also violate the 
        equilibrium assumption.   Conclude the return on a security with $\beta=1$ must 
        be the same as the market portfolio
        \item The excess return for a security with $\beta \neq 1$ is given 
        by the equilibrium condition to be $\beta (E[r_m]-r_f)$
    \end{itemize}
    
\end{frame}

\begin{frame}[t]
    \frametitle{3. Implications of CAPM Equilibrium}
    \framesubtitle{Prices Adjust}

    Let's say Stock A lies \textit{above} the SML.  What is the reward-to-risk of this security?
    
    $$
    \begin{aligned}
    \text{Reward:} &\quad E[r_{A}]-r_f = \beta_{A}(E[r_m]-r_f) + \alpha\text{, where }\alpha>0 \\
    \text{Risk:} &\quad Cov(r_{A},r_m) 
    \end{aligned}
    $$

    Notes:
    \begin{itemize}
        \item Because A is above the SML: $E[r_{A}]-r_f = \beta_i(E[r_m]-r_f) + \alpha\text{, where }\alpha>0$
        \item The investor is already assumed to hold the market portfolio, therefore security A is evaluated from the perspective of how it would change the investors risk, which is given by the Covariance of A with the market (not by the Variance of A)
    \end{itemize}
   
\end{frame}

\begin{frame}[t]
    \frametitle{3. Implications of CAPM Equilibrium}
    \framesubtitle{Prices Adjust}

    \footnotesize
    The reward-to-risk ratio of security A is

\[
\frac{E[r_A]-r_f}
     {\operatorname{Cov}(r_A,r_m)}.
\]

Using

\[
\beta_A
=
\frac{\operatorname{Cov}(r_A,r_m)}
     {\operatorname{Var}(r_m)},
\]

and then using the fact that A is above the SML, we obtain

\[
\frac{E[r_A]-r_f}
     {\operatorname{Cov}(r_A,r_m)}
=
\frac{E[r_m]-r_f}{\operatorname{Var}(r_m)}
+
\frac{\alpha}
     {\operatorname{Cov}(r_A,r_m)}.
\]

Therefore, when $\alpha>0$,

\[
\frac{E[r_A]-r_f}
     {\operatorname{Cov}(r_A,r_m)}
>
\frac{E[r_m]-r_f}
     {\operatorname{Var}(r_m)}.
\]


    Therefore, if $\alpha > 0$, A has \textit{better} reward-to-risk than the market.   Investors will \textit{buy} security A.

\end{frame}

\begin{frame}[t]
    \frametitle{2. Implications of CAPM Equilibrium}
    \framesubtitle{Prices Adjust}

    Eventually all securities end up back on the SML:
    \begin{itemize}
    \item If a security lies \textit{above} the SML, then it has \textit{better} reward-to-risk than the market portfolio.   Investors will \textit{buy} that security.   As investors buy, this will cause the price to \textit{rise}.   As the price rises, the expected return on the security will \textit{decline}.   It will continue declining until the security lies on the SML and investors have no further incentive to buy or sell.
    \item The converse happens if a security is \textit{below} the SML.   Investors will sell this security, prices will fall and expected returns will increase until it lies on the SML.
    \end{itemize}
    The adjustment of security prices until expected returns are consistent with
    the SML is what characterizes the CAPM \textbf{equilibrium}.

\end{frame}
